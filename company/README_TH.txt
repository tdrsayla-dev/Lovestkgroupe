LOVE STK GROUPE — Website files

แต่ละหน้าแยกเป็น 3 ไฟล์: .html / .css / .js
ไฟล์ทั้งหมดอยู่ระดับเดียวกัน เพื่อให้เมนูและลิงก์ระหว่างหน้าทำงานได้

index        หน้าแรก + เกี่ยวกับเรา + แนวทางของเรา + ติดต่อเรา
businesses   ธุรกิจในเครือ
leadership   ผู้บริหาร
news         ข่าวสาร
news-article รายละเอียดข่าว
products     ผลิตภัณฑ์
product      รายละเอียดสินค้า (เปิดจากหน้าสินค้า)
admin        จัดการเว็บไซต์
about        หน้าเปลี่ยนเส้นทางไปหน้าแรก (เพื่อรองรับลิงก์เดิม)

วิธีเปิด
1. แตก ZIP ทั้งชุด ห้ามย้ายหรือแยกโฟลเดอร์ assets
2. เปิด index.html ในเบราว์เซอร์ หรือใช้ VS Code Live Server
3. สามารถเปิดด้วย Python: python -m http.server 8000
   แล้วเข้า http://localhost:8000

ข้อมูล
- ชุดนี้มีข้อมูลตัวอย่างจาก source ของเว็บไซต์ รวมสินค้า 10 ตัว ข่าว และราคาตัวอย่าง
- ข้อมูลตัวอย่างถูกฝังไว้ใน JS ของแต่ละหน้า ไม่ใช่การสำรองข้อมูล CMS ที่ผู้ดูแลแก้ไขภายหลัง
- หากวางไว้บน host เดียวกับ backend เดิม หน้าเว็บจะโหลด /api/content จาก backend ก่อน
- CSS รวมสไตล์หน้าเว็บและ Dark / Light ตามลำดับเดิม
- JS รวมเมนู ภาษา ธีม แกลเลอรี สไลด์ และพฤติกรรมของหน้านั้น
- Font จาก Google Fonts และลิงก์ระบบบริษัทภายนอกต้องใช้อินเทอร์เน็ต

ระบบจัดการเว็บไซต์
admin.html / admin.css / admin.js คือส่วนหน้าเท่านั้น
การเข้าสู่ระบบ บันทึก เผยแพร่ และอัปโหลดรูป ต้องมี backend เดิม:
/api/admin/content, /api/admin/publish, /api/admin/upload พร้อมระบบยืนยันตัวตน
ข้อมูลของหน้า admin ไม่ได้บันทึกบนเครื่องโดยอัตโนมัติ
cms-fields.json คือรายการช่องแก้ไขของ admin

ไฟล์ชุดนี้เป็นสำเนาสำหรับดาวน์โหลด เว็บไซต์ที่ออนไลน์อยู่ไม่ได้ถูกเปลี่ยนแปลง
